Limits — not a pixel-perfect certification

Six original source videos are missing locally; cached extracted frames were used, which cannot establish every intervening motion frame. Some user-requested custom variants have no one-to-one reference shot. ESPN headshots cannot reproduce full-body illustrated reference artwork. Hardware camera inputs, actual Stream Deck hardware and OBS capture were not exercised in this visual audit. AR was not modified; ar-link.js only received an import cache-version update.

Review

Install
Extract the UPDATE ZIP and replace the corresponding files in your existing package, preserving folders. This is a changed-files update, not a standalone full installation. Open index.html with Live Server, or upload the extracted files together to your existing GitHub Pages repository. No Python is required to run the graphics.
